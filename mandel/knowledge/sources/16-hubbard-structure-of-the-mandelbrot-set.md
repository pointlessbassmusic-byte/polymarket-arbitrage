## What it says (core ideas)

The lecture's own framing is best given by Hubbard's abstract for the identically titled colloquium of 14 November 2025, reproduced here in full because it is short and is the only text by the speaker about this talk:

> "Let f : X → X be a map. One object of dynamical systems is to understand the behavior of sequences x, f(x), f(f(x)), ... This is not understood in any generality, but quadratic polynomials p_c(z) = z² + c are quite well understood, though the theory is amazingly intricate. For quadratic polynomials (for polynomials more generally) there is one behavior that always exists: if |z| is big enough, the sequence z, p(z), p(p(z)), ... tends to infinity. Let K_c be the set of z whose orbit does not tend to infinity. These sets K_c can be amazingly complicated, but for quadratic polynomials p_c(z) = z² + c, there is a dichotomy: 1. Either K_c is connected, which occurs if and only if 0 ∈ K_c, or 2. K_c is a Cantor dust, which occurs if and only if 0 iterates to infinity. The set of c with K_c connected is called the Mandelbrot set M. It is easy to write programs to draw the Mandelbrot set, but especially after looking at a few blowups, you will see that a description cannot be simple. But a description can be given, involving a strange numerology where the digits of angles written in base 2 reflect the dynamics of polynomials."

The items below unfold that abstract with the mathematics Hubbard would be drawing on.

1. **The object is iteration, and quadratics are the tractable case.** [abstract] Dynamics asks what the sequence x, f(x), f(f(x)), ... does; for general maps "this is not understood in any generality". Every quadratic polynomial is affinely conjugate to exactly one p_c(z) = z² + c, so the whole quadratic family is one complex parameter c, and p_c has a single critical point, z = 0 (where p_c'(z) = 2z vanishes). One parameter and one critical point is the simplest nonlinear situation, and it already contains everything in this file: "quite well understood, though the theory is amazingly intricate".

2. **Escape, the filled Julia set and the Julia set.** [abstract][Orsay] For |z| large the orbit tends to ∞: if |z| > max(2, |c|) then |z² + c| ≥ |z|² − |c| > |z|, and the orbit escapes at a doubling-exponential rate. K_c = {z : p_c^n(z) does not tend to ∞} is the filled Julia set, a compact set; J_c = ∂K_c is the Julia set, where the dynamics is chaotic (dense repelling cycles, sensitive dependence). The escape bound also gives the drawing algorithm: iterate from z, stop when |z_n| > 2, colour by n. [general]

3. **The dichotomy, decided by one orbit.** [abstract][Orsay, Fatou–Julia 1919] K_c is connected if 0 ∈ K_c, that is if the critical orbit 0 ↦ c ↦ c² + c ↦ ... stays bounded; otherwise K_c is a Cantor set ("Cantor dust": compact, totally disconnected, uncountable). The mechanism is the Böttcher coordinate: near ∞ the map p_c is conjugate to z ↦ z² by φ_c(z) = lim_{n→∞} (p_c^n(z))^{1/2^n}, tangent to the identity at ∞, and the conjugacy extends inward until it meets a critical point. If 0 escapes, the extension stops at the equipotential through 0 and K_c breaks into pieces at every stage; if 0 does not escape, φ_c extends to all of C \ K_c, so C \ K_c is a punctured disc and K_c is connected and full. Potential: G_c(z) = log|φ_c(z)| = lim 2^{−n} log|p_c^n(z)|, harmonic off K_c, zero on K_c, with G_c(p_c(z)) = 2 G_c(z). [Orsay Ch 8]

4. **The Mandelbrot set is the parameter space of this dichotomy.** [abstract][Orsay Ch 1] M = {c : K_c is connected} = {c : 0 ∈ K_c} = {c : the orbit of 0 under p_c is bounded}. Because p_c(0) = c, the critical value is the parameter itself, so M = {c : c ∈ K_c} as well. M is compact (contained in |c| ≤ 2), connected (item 6) and full. The Orsay notes also define M' = {c : p_c has an attracting cycle}, which is open and contained in M; its connected components are the hyperbolic components (item 9). Each point of M labels an entire dynamical system; the c-plane (parameter space) and the z-plane (dynamical space) are different planes, and the subject is the dictionary between them: M is a catalogue of the Julia sets K_c, indexed by c.

5. **Blow-ups show the structure cannot be simple; the binary digits of angles describe it anyway.** [abstract] "It is easy to write programs to draw the Mandelbrot set, but especially after looking at a few blowups, you will see that a description cannot be simple. But a description can be given, involving a strange numerology where the digits of angles written in base 2 reflect the dynamics of polynomials." The mechanism is angle doubling. φ_c conjugates p_c to z ↦ z², and squaring doubles the argument, so the external ray of angle θ ∈ R/Z maps to the ray of angle 2θ (mod 1). Doubling is the left shift on the binary expansion of θ, so the binary digits of an angle are the itinerary of the corresponding orbit with respect to a two-piece partition of the plane (the kneading sequence); periodic angles have periodic expansions, and the angle p/(2^n − 1) has period n under doubling. The combinatorics of p_c can therefore be read from binary digits, and conversely the angle of a parameter ray is computed from the dynamics of p_c (item 8). This is the "numerology" the abstract promises and the thread of the whole talk.

6. **Theorem (Douady–Hubbard, 1982): M is connected.** [Orsay Ch 1, Ch 8][general] The proof constructs Φ_M : C \ M → C \ D̄ by Φ_M(c) = φ_c(c), the Böttcher coordinate of p_c evaluated at its own critical value; equivalently Φ_M(c) = lim (p_c^n(c))^{1/2^n}, normalised so that Φ_M(c)/c → 1 at ∞. Φ_M is a conformal isomorphism, so C \ M is a punctured disc and M is connected and full. The Orsay notes add in a footnote: "It is rather easier to find the conformal mapping of C \ M than of the complement of a triangle." Mandelbrot had at first read his pictures as a main island with disconnected satellites; the filaments joining them were below pixel resolution, and the proof showed they are there. [Quanta][general] Kahn gave a topological proof in 2001. [general]

7. **Potential, equipotentials, external rays of M; rational rays land.** [Orsay Ch 1, Ch 8, Ch 13] G_M(c) = log|Φ_M(c)| is the Green's function (potential) of M: harmonic off M, zero on M, asymptotic to log|c|. Its level curves are the equipotentials and their orthogonal trajectories the external rays R(M, t) = Φ_M^{−1}({ρ e^{2πit} : ρ > 1}), t ∈ T = R/Z, "arguments counted in turns, not modulo 2π". A ray lands if Φ_M^{−1}(ρ e^{2πit}) converges as ρ → 1; the limit then has external argument t. If M were locally connected every ray would land (Carathéodory). Theorem: every external ray of M with rational argument lands. If t has odd denominator (t periodic under doubling), R(M, t) lands at a parabolic parameter, one where p_c has a rationally indifferent cycle (multiplier a root of unity); every such c except c = 1/4 (t = 0) is the landing point of exactly two rays. If t has even denominator (t strictly preperiodic), R(M, t) lands at a Misiurewicz point, where the orbit of 0 falls onto a repelling cycle; such a point has finitely many external arguments, all rational with even denominator. The Orsay figures label angles 1/7, 2/7, 4/7 (a period-3 cycle under doubling), 1/4, 1/2, and 1/5, 4/15, 9/56, 11/56, 15/56; the rays 1/3 and 2/3 land at c = −3/4, the root of the period-2 component, and 1/7, 2/7 at the root of the period-3 bulb above the cardioid. [general] Without MLC it is not known that every irrational ray lands.

8. **Hubbard trees compute the angles.** [Orsay Ch 1, 4, 6, 7, 8, 18] For c a centre of a hyperbolic component (0 periodic) or a Misiurewicz point, the Hubbard tree is the smallest tree in K_c joining the critical orbit and passing through the centres of the bounded Fatou components it meets; p_c acts on the tree. From the tree one computes the external arguments of c in M: for a Misiurewicz point its finitely many arguments, for a centre the two arguments of the root of its component ("rather elementary in the case of Misiurewicz points, ... more tricky for the roots of hyperbolic components"). One then shows every rational angle arises this way. Conversely (Orsay Ch 6, and later the Hubbard–Schleicher spider algorithm) a polynomial is reconstructed from an abstract tree. A corollary (Orsay Cor 6.3) settles the Metropolis–Stein–Stein conjecture: two real quadratics with 0 periodic of the same period and the same ordering of the critical orbit on the line are the same polynomial, so the combinatorial itinerary determines the parameter.

9. **Hyperbolic components: centre, root, multiplier.** [Orsay Ch 1, Ch 14][Milnor Thm 6.5] For each connected component U of M' and each c ∈ U, p_c has a unique attracting cycle {z_0(c), ..., z_{k−1}(c)} of some period k, and the multiplier map ρ_U : c ↦ (p_c^k)'(z_0(c)) is a conformal isomorphism U → D that extends injectively to the boundary; the closure of U is a closed disc. The centre is ρ_U^{−1}(0), where 0 itself is periodic (superattracting); the root is ρ_U^{−1}(1), where the cycle is parabolic. The main cardioid (period 1) is c(μ) = μ/2 − μ²/4, |μ| < 1; the period-2 component is the disc |c + 1| < 1/4, attached at c = −3/4. [general] At internal angle p/q on a component's boundary (multiplier e^{2πip/q}) a satellite component of q times the period is attached by tangency, while a primitive component has a cusp at its root [Milnor Lemmas 6.1, 6.2]; every parabolic point is the root of exactly one component, so parabolic points and components correspond one-to-one [Milnor 6.3]. Counting: the centres of period n are the roots in c of p_c^n(0), a polynomial of degree 2^{n−1}; the parabolic points of ray period n number ν_2(n)/2 where ν_2(n) counts the period-n points of z ↦ z². [Milnor Cor 5.3]

10. **Orbit portraits, wakes and limbs: the combinatorial skeleton.** [Milnor, reformulating Douady–Hubbard] The two parameter rays of angles t_± landing at a parabolic point r_P bound a wake W_P: p_c has a repelling orbit with the given portrait P (the pattern of dynamic rays landing on the orbit) if and only if c ∈ W_P, and a parabolic one if and only if c = r_P [Thm 1.2]. The limb M_P = M ∩ closure(W_P) is connected even with its root removed [Cor 9.3], and every point of a limb is either in the closure of the component H_P or in some satellite limb [Thm 9.1]. Wakes are disjoint or nested (orbit forcing, Cor 1.3), so M is organised as a tree of wakes indexed by pairs of binary-periodic angles, and "every periodic angle occurs" as a wake boundary [Thm 1.5]. Milnor states the method: "As in [DH1], the basic idea is to find properties of M by a careful study of the dynamics for parameter values outside of M."

11. **The two conjectures, MLC and HG2, and the theorem MLC ⇒ HG2.** [Orsay Ch 1, Ch 22] "The two main conjectures are the following: (MLC) The set M is locally connected. (HG2) The interior of M is M'." Theorem 22.4: if M is locally connected, every connected component of the interior of M is hyperbolic; there are no "ghost" components, open regions of M whose maps have no attracting cycle. The proof: under MLC the Carathéodory loop T → ∂M is surjective, so every boundary point has an address; three boundary points of a ghost component would be separated by rays of dyadic angle landing at Misiurewicz points or centres whose Hubbard trees force a contradiction. Hubbard in 2024: MLC "gives a name to every dot", and with it "you can hope to really understand it completely" [Quanta]. The pinched-disc model (identify points of the circle whose rays land together) would then be an exact topological description of M. [general] HG2 is the density of hyperbolicity for the quadratic family, called by the Wikipedia article one of the most important open problems in complex dynamics. [general]

12. **Status of MLC as of the sources read.** [Hu93][Orsay footnote][Quanta] Yoccoz (around 1990, written up in Hubbard's "three theorems" paper): M is locally connected at every c with an indifferent cycle (Thm I.C) and at every c that is not infinitely renormalizable (Thm III: such c has a basis of closed connected neighbourhoods in M); on the dynamical side K_c is locally connected when c is not infinitely renormalizable and has no indifferent cycle (Thm II). Lyubich, Kahn–Lyubich and Dudko–Lyubich (using Dudko–Selinger's renormalization theory) proved MLC at many infinitely renormalizable parameters; Kapiamba sharpened a Yoccoz estimate near the cusp of the cardioid; in January 2024 a complete proof remained open and the remaining cases were described as "the last ones". No source read here reports a proof since. HG2 is proved on the real line (Lyubich; Graczyk–Świątek, 1990s) and open in the plane. [general]

13. **Yoccoz's puzzle: Markov partitions with a critical point, and the Yoccoz inequality.** [Hu93] Hubbard frames the method as making the "Markov philosophy" work: "Given a dynamical system f : X → X, cut up the dynamical space into pieces ... assign to a point x ∈ X the sequence of pieces which its orbit visits"; this is useful only when the identifications induced by the itinerary map can be understood, which classically required hyperbolicity. Yoccoz's puzzle pieces (regions bounded by an equipotential and the rays landing at the α fixed point, pulled back) give a criterion (Thm 9.5) under which the itinerary determines the point even with a critical point present, and the parapuzzle transports the argument to the c-plane. Yoccoz's inequality (Thm I.B): for a repelling fixed point of a degree-d polynomial with connected K, combinatorial rotation number p/q and m cycles of rays, some branch τ of log P'(z_0) satisfies Re τ / |τ − 2πip/q|² ≥ mq / (2 log d), equivalently τ lies in the closed disc of radius (log d)/(mq) tangent to the imaginary axis at 2πip/q. In parameter space this bounds the diameter of the p/q-limb by O(1/q); numerically the limbs shrink like 1/q². [general]

14. **Polynomial-like maps and the straightening theorem.** [DH85] A polynomial-like map of degree d is a triple (U, U', f) with U' relatively compact in U, both open discs, and f : U' → U analytic and proper of degree d; its filled Julia set is K_f = ∩_n f^{−n}(U'). Straightening theorem: every polynomial-like map of degree d is hybrid equivalent (quasiconformally conjugate on a neighbourhood of K_f, with the conjugacy conformal on K_f) to a polynomial of degree d, unique up to affine conjugacy when d = 2 and K_f is connected; the proof uses the measurable Riemann mapping theorem (Morrey–Ahlfors–Bers). The motivation, in the authors' words: the notion "was motivated by the observation that when studying iteration of polynomials, one uses the theory of analytic functions continually, but the rigidity of polynomials only rarely", and "many dynamic properties of polynomials extend to the framework of polynomial-like mappings. In fact, you can often simply copy the proof in the new setting."

15. **Renormalisation, tuning, and the small copies of M in M.** [DH85 Ch V][Milnor §8] Let c_0 be the centre of a period-k component. Near 0, p_{c_0}^k behaves like z ↦ z²; for c near c_0, the restriction of p_c^k to a suitable disc U' is still polynomial-like of degree 2, so straightening assigns to it a quadratic z² + χ(c). The set of c for which this small filled Julia set is connected is χ^{−1}(M) = M_{c_0} ⊂ M, and χ is a homeomorphism onto M when the component is primitive ("tunable") or onto M \ {1/4} with a continuous inverse when it is a satellite ("semi-tunable"). Milnor's Theorem 8.2 (Douady–Hubbard tuning): for each non-trivial orbit portrait P the map c' ↦ P ∗ c' is a continuous embedding of M into itself whose image is the small Mandelbrot set P ∗ M; there is a composition P, Q ↦ P ∗ Q with (P ∗ Q) ∗ c = P ∗ (Q ∗ c), and the portraits form a free non-commutative monoid under it. The angles of rays landing on a small copy form a middle-fraction Cantor set inside the characteristic arc [t_−, t_+]. A parameter inside infinitely many nested copies is infinitely renormalizable, exactly the case Yoccoz's theorem excludes; the real Feigenbaum point c ≈ −1.4011551 (limit of period doubling, repeated tuning by the period-2 portrait) is the standard example. [general] Milnor: "One remarkable property of the Mandelbrot boundary is that it is densely filled with small copies of itself." The copies are homeomorphic to M, not similar: M is quasi-self-similar, and each copy is dressed in different filaments.

16. **Universality: copies of M appear in every analytic family.** [DH85 intro][McM] Douady–Hubbard's Figure 4 is the λ-plane of Newton's method for the cubics f_λ(z) = (z − 1)(z + 1/2 + λ)(z + 1/2 − λ) started at the inflection point z_0 = 0, "the worst possible initial guess" because any attracting cycle other than the roots must attract the critical point 0. The white region where Newton's method fails to converge "looks remarkably like M", and "the ressemblance extends to the finest detail". Their explanation: for λ_0 at the centre, N_{λ_0}^k is superattracting at 0 and behaves like z², and nearby λ gives z² + χ(λ); "If f_λ is any family of analytic functions depending analytically on λ, then an attempt to classify values of λ according to the dynamical properties of f_λ will often produce copies of M in the λ-plane." McMullen (1997, published 2000) made this a theorem: for any holomorphic family of rational maps over the disc the bifurcation locus is empty or contains quasiconformal copies of ∂M_d (M_d the degree-d Mandelbrot set); "small Mandelbrot sets are dense in B(f)"; the sets M_d are "initial objects in the category of bifurcations, providing a lower bound on the complexity of B(f) for all families". A corollary: every bifurcation locus has Hausdorff dimension 2.

17. **The boundary is as rough as a plane set can be, and near special points M looks like the Julia set it indexes.** [general; Shishikura, Stony Brook preprint 1991, Annals 1998; McM Thm 1.5] dim_H ∂M = 2 while its topological dimension is 1, and dim_H J_c = 2 for a dense G_δ of c ∈ ∂M; whether ∂M has positive area is open. Tan Lei (1990): at a Misiurewicz point c, successive magnifications of M and of J_c by the multiplier of the repelling cycle converge to the same limit set, so the parameter picture near c is asymptotically the dynamical picture at c. [general, from memory of the theorem; the paper's abstract could not be fetched here]

18. **Pictures propose, proofs decide; the role of computation.** [DH85][Quanta][Cornell page] The Orsay programme ran on computer pictures (Homer Smith "wrote the programs which drew the pictures" for the 1985 paper); the pictures first misled on connectedness and then suggested the right theorem, revealed the small copies that renormalisation explains, and motivate MLC. ## What Mandel adopts

- **Keep parameter space and dynamical space as two different planes, with an explicit dictionary between them.** Because every confusion in the subject comes from mixing the c-plane with the z-plane: M is a picture of parameter space whose every point is a whole dynamical system, and Mandel's catalogue of strategy and model settings is likewise a space whose every point is a whole behaviour, to be kept apart from the market state those behaviours act on.
- **Find the critical orbit: one diagnostic trajectory decides the global class.** Because K_c is connected or dust according to the orbit of the single critical point; Mandel should identify, for each strategy class, the one cheapest quantity whose out-of-sample trajectory decides membership in the validated set, and run it before any full backtest.
- **Study the exterior to understand the interior.** Because Φ_M, the rays and the whole combinatorics come from the dynamics for c outside M ("the basic idea is to find properties of M by a careful study of the dynamics for parameter values outside of M"); the structure of what works is mapped by the structure of what fails, so rejected proposals are data to be organised, not waste.
- **Name every point by its angle: addresses computed from the dynamics, not assigned by hand.** Because external arguments are computed from the itinerary (binary digits) and two parameters with the same argument pattern are the same parameter (Metropolis–Stein–Stein); Mandel's identifiers for decisions and insights should be derived from their evidence itinerary so that identical reasoning is recognised as identical and near-identical reasoning is adjacent.
- **Record validated regions, each with a centre, a root and a multiplier, rather than single best settings.** Because a hyperbolic component is a region of parameter space with one stable qualitative behaviour, uniformised by the multiplier (how strongly attracting), with a centre (the best-behaved point) and a root (where it bifurcated from its parent); the same three coordinates describe a validated region of Mandel's settings: the margin by which the gate held, the settings with the largest margin, and the proposal it grew out of.
- **Treat boundaries as where behaviour changes: the bifurcation locus is ∂M.** Because every delicate object (parabolic points, Misiurewicz points, dimension 2) lives on the boundary and a small move across it changes the qualitative outcome; a candidate near a known region boundary needs more out-of-sample evidence than one deep inside.
- **Renormalise honestly: a sub-loop may reuse the parent's theory only after a straightening check, and should expect a homeomorphic copy with different decorations.** Because Douady–Hubbard reuse the quadratic theory inside a small copy only when the restricted iterate is polynomial-like (U' relatively compact in U, proper, degree 2), and the copies are homeomorphic, not similar; ORIGINAL-IDEAS #7 ("the same loop at four scales") needs analogous conditions before a child's inner loop inherits Mandel's gate, and must re-derive its budgets and thresholds rather than copy them.
- **Expect universality, then test it.** Because copies of M appear in every analytic family (McMullen), so the same region/centre/root/boundary structure should appear in every child's parameter space, but the theorem gives quasiconformal copies, not identical settings; transfer between children or markets requires a transfer test (A1's lesson).
- **Hold conjectures as first-class objects with status, implications and partial results.** Because the Orsay notes open by stating MLC and HG2, prove MLC ⇒ HG2, and footnote what Yoccoz later proved; Mandel's store should hold its open hypotheses the same way: statement, what they would imply, what is proved so far, and what would decide them.
- **Pictures suggest theorems; the gate decides.** Because pictures misled Mandelbrot on connectedness and later suggested the small copies, MLC and dimension 2, and in every case the proof came afterwards; the signal map and backtest plots are generators of hypotheses, never evidence.
- **Prefer the weakest structure that lets the proofs be copied.** Because polynomial-like maps were invented on noticing that "one uses the theory of analytic functions continually, but the rigidity of polynomials only rarely"; Mandel's abstractions (the child interface, the evaluator protocol, the proposal schema) should demand only what the validation argument actually uses, so that the same gate applies to new children without rewriting.

## What Mandel holds loosely or rejects

- **Markets are not holomorphic dynamics.** z² + c predicts nothing about prices; the transferable content is the method (parameter space, stability regions, addresses from itineraries, renormalisation discipline), not the map, the set, or its pictures.
- **Visual resemblance between M or Julia sets and price charts is not evidence of anything.** Tan Lei similarity and McMullen universality are theorems about holomorphic families with a conformal structure; time series have none.
- **Exact self-similarity of Mandel's own loop across scales (ORIGINAL-IDEAS #7) is an expectation to test, not a design fact.** Copies of M are homeomorphic, not similar, and the infinitely renormalizable parameters are precisely the hard cases; if the levels need different procedures in practice the design should drop the analogy, as that idea's own falsification clause says.
- **"Every stable region has a mechanism" is the HG2 analogue and is unproved even for M.** Mandel may find regions of settings that pass the gate with no identifiable reason (ghost components); it must label them as such and cap their confidence rather than invent a mechanism after the fact.
- **Clean escape criteria do not transfer.** |z| > 2 implies escape because of algebra; there is no theorem that a strategy whose drawdown crosses a threshold never recovers, so Mandel's stop rules are budget decisions that must be pre-registered as decisions, not presented as laws.
- **The specifics of the 2013 colloquium are inferred.** Venue (KAIST), order of topics and pictures come from a title string, a search snippet, and Hubbard's abstract for later talks of the same title; "What it says" is his programme, not a transcript.
- **Universality is not a licence to copy settings between children or markets.** Existence of a copy of the structure is not identity of the parameters.
- **Do not cite MLC as settled.** As of the sources read (January 2024 and earlier) it is open; Mandel re-checks before stating a status.

## Design implications for the RSI predictive substrate

- **`ParameterRegion` record in the ProposalBook.** Fields: target, strategy_id, param_ranges (the box of settings over which the gate held across the walk-forward windows), centre (the settings with the largest gate margin), root (the proposal id this region bifurcated from, with kind primitive or satellite), multiplier (the gate margin normalised to [0, 1), for example 1 − achieved/required deflated Sharpe, or the Brier-skill margin over the market), boundary (rejected neighbouring settings). A query `region_map(target)` returns regions, gaps and boundaries; a region is the unit of what Mandel claims to know about a strategy's settings.
- **Boundary flag in the gate.** If a candidate's settings lie within one grid step of a rejected neighbour or of an accepted region's edge, the gate requires one additional out-of-sample window before deciding. Metrics: boundary_flag_rate (fraction of proposals flagged) and boundary_flip_rate (how often the extra window changed the verdict).
- **Critical-orbit probe before full evaluation.** Each strategy class declares one critical quantity (for example rolling out-of-sample Brier skill against the market price at forecast time) and a pre-registered escape radius (a loss bound). The first, cheapest fold runs only the critical orbit; candidates that escape stop early and are logged with their escape time (folds survived), a continuous colouring like the escape-time algorithm, rather than a bare reject. This is the staged evaluation of A1 and A2 with a named diagnostic.
- **Itinerary identifiers next to provenance hashes.** Every gate decision path is recorded as a binary string, one bit per stage or fold (pass or fail), stored with the proposal. Two proposals with identical itineraries and the same provenance class are flagged as candidate duplicates; the prefix order on itineraries retrieves the nearest prior decision when a new proposal arrives, so negative results are found by address rather than by search.
- **Straightening check for ORIGINAL-IDEAS #7.** Before a sub-scale loop (a child, a strategy inside a child, a single forecast) reuses the parent gate, three conditions are checked and logged: domain (its data and budget are a proper subset of the parent's, the analogue of U' relatively compact in U), properness (each sub-proposal maps to exactly one parent observation), degree (exactly one critical quantity). If any fails, the level receives its own written gate with its own thresholds. Metrics: renormalisation_depth (nested loops that passed) and straightening_failures.
- **Tuning operator for proposals.** `tune(P, Q)` applies proposal Q inside the region validated by P; the result's region is recorded as P ∗ Q with lineage. The test suite checks associativity on recorded compositions ((P ∗ Q) ∗ R and P ∗ (Q ∗ R) must yield the same region), as a regression test that composing accepted changes is well defined.
- **Conjecture registry.** A file `mandel/state/conjectures.jsonl` with entries {id, statement, status in {open, partial, proved, refuted}, implies [ids], partial_results [refs], deciding_metric, last_checked}, seeded with ORIGINAL-IDEAS #1-7 as conjectures (for #2: "Mandel's Brier score on its own proposals falls over the first fifty", with the metric and threshold named).
- **Exterior-first weekly job.** Over rejected proposals compute a potential G = log(required_margin / achieved_margin), the distance outside the gate, and an angle, the itinerary prefix at which the proposal failed; report equipotential bands (how far from acceptance the rejects sit) and the distribution of angles (which failure modes dominate). Metric: median potential of rejects per target and its trend.
- **Ghost-region detector.** Any accepted region whose proposal records no mechanism field (the stated reason the edge should exist) is counted as a ghost; the metric ghost_regions should be 0, and a ghost region's insights are capped at the inference-only confidence (0.5) until a mechanism is recorded and independently supported.
- **Signal-map parameter-space view.** For a chosen strategy, plot the settings tried so far coloured by gate outcome and escape time, with accepted regions outlined and centres and roots marked; it is an instrument for choosing the next proposal (ORIGINAL-IDEAS #6), never evidence.
- **Metrics summary.** regions_per_target, mean_multiplier of accepted regions, boundary_flag_rate, boundary_flip_rate, escape_time distribution, renormalisation_depth, straightening_failures, ghost_regions, median reject potential.

## Cross-links to other provided resources

- **15 (3Blue1Brown, fractal dimension):** Shishikura's dim_H ∂M = 2 is 15's "roughness as a measurable exponent" at its maximum for a plane curve; both resources reject exact self-similarity as the definition of a fractal, 15 by the box-counting definition, 16 by the fact that the small copies of M are homeomorphic but not similar.
- **08 and 09 (iterated function systems):** IFS attractors are exactly self-similar and their dimension follows from k and s; M is not an IFS attractor, so 09's warning that the similarity-dimension formula does not apply is correct. The straightening theorem is the subject's weaker notion of "the same up to a change of coordinates" (hybrid equivalence), which is what Mandel's cross-scale analogy actually has.
- **11 (Veritasium, Markov chains):** both iterate a map. Yoccoz's puzzle is explicitly the "Markov philosophy" (assign to each point the sequence of pieces its orbit visits) made to work with a critical point present; the attracting-cycle criterion |multiplier| < 1 is the same stability test as a chain's second eigenvalue, and 11's stationary distribution plays the role of the attracting cycle.
- **04 (Emergent Garden, recursive self-improvement):** 04 trains a network on the Mandelbrot set using a log-distance target computed from the derivative dz/dc of the critical orbit, that is from the potential of item 3; its harness/solution separation is a parameter-space/dynamical-space separation; and its "same loop again" structure is what ORIGINAL-IDEAS #7 and the straightening check here try to make honest.
- **05 (3Blue1Brown, neural networks) and 07 (Mchara, linear models to deep networks):** gradient descent moves through a parameter space whose basins are the analogue of hyperbolic components, with the local convergence rate (Hessian eigenvalue) as the multiplier; 07's "universal approximation is true and nearly useless" is the same kind of statement as McMullen's universality: existence, not construction.
- **10 (Batra, linear algebra ideas):** the multiplier of a cycle is the derivative, that is the eigenvalue of the linearisation, at a fixed point of p_c^k, and attraction is |λ| < 1; the Yoccoz inequality is a bound on a logarithm of that eigenvalue.
- **12 and 13 (AI Pathways):** 12's deterministic/non-deterministic split puts fixed-rule code in the role of the dynamical system and the model in the role of the parameter-chooser, which is the c-plane/z-plane split; 13's HMM regimes are a small finite catalogue of behaviours indexed by hidden state, with the same caveat that labels are assigned after the fact.
- **14 (DaviddTech, trading-bot pipeline):** parameter optimisation in a backtester is a walk through parameter space; an over-fitted setting is a point on a filament (qualitatively unstable under a small move), a robust one lies inside a component (a plateau); the boundary flag and region records here are the structural form of 14's incubation and robustness rules.
- **01 (Seife, information):** a bit is one yes/no, and the binary digits of an external angle are exactly the yes/no itinerary bits of an orbit; MLC is the statement that every boundary point has such an address, that is a code; the Böttcher coordinate compresses the entire exterior dynamics to one angle and one potential.
- **06 (Herk, second brain):** the Hubbard tree is the minimal connecting structure of a Julia set from which the angles are computed, a "map, not an essay"; 06's router file plays the same role for a knowledge base.
- **02 and 03 (Mossbridge):** connected only methodologically: hold conjectures as conjectures with status and partial results (item 11-12), and let pictures suggest while tests decide.
- **A1 (Darwin Gödel Machine) and A2 (AlphaEvolve):** A1's archive with lineage is the root/bifurcation record of regions; A2's evaluation cascade and A1's staged evaluation are the critical-orbit probe with escape time; A1's transfer results are the empirical form of "expect universality, then test it".
- **A3 (Agentic Context Engineering):** structured bullets with ids and counters are the address scheme applied to insights; the itinerary identifier here is a more specific id.
- **A4 (Mandelbrot's multifractal model):** the namesake's market programme. The MSM's geometric progression of switching frequencies is a cascade of scales like period doubling; A4's lesson that an unestimable model needed an estimable successor is the straightening check applied to a model family.
- **A5 (Halawi et al., LLM forecasting):** the Brier skill against the crowd at forecast time is the natural critical quantity for Mandel's critical-orbit probe.
